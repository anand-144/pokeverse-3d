## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/pokeverse-3d.git
```

Navigate to project:

```bash
cd pokeverse-3d
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build project:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
